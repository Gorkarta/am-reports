# Аренамастер Бизнес-аналитика — данные дашбордов с GitHub

Версия 1.1 · 23.10.2026.

## Как это работает
1. Выгрузка БС появляется в приватном `Gorkarta/bs-reports` (`csv/`) около 09:00 МСК.
2. Workflow `Расчёт дашбордов Аренамастер` (`bs-reports/.github/workflows/dashboards.yml`, копия — `dashboards/workflow/dashboards.yml`) запускается на этот коммит, берёт свежую и прошлую выгрузки (из истории git), запускает `dashboards/src/build_all.py` и коммитит результат сюда.
3. Дашборды портала при открытии запрашивают свой файл из `dashboards/data/` (raw.githubusercontent.com). Если свежих данных ещё нет, на странице строка «Идёт обновление…» и раз в 2 минуты проверка `meta.json`; новые данные подхватываются автоматически. Если GitHub недоступен — показывается встроенный снимок, строка статуса красная.

## Файлы
| Путь | Что |
|---|---|
| `data/meta.json` | время выгрузки по каждому файлу (`files`), время расчёта |
| `data/pf_page.json` | «Портфель мероприятий Live Арена» (готовые блоки + данные по мероприятиям) |
| `data/channels.json` | «Каналы продаж — портфельная аналитика» |
| `data/blocked.json` | есть только если «Портфель» остановлен проверкой подозрительных мероприятий |
| `archive/ДДММГГГГ/` | копия данных за день |
| `src/` | скрипты расчёта и сборки оболочек дашбордов |

В публикуемых файлах нет персональных данных: только агрегаты по мероприятиям и каналам. Скрипты не читают `tickets.data`, `individuals`, `payments`.

## Если «Портфель» остановился (код 2)
Workflow завершится с ошибкой, в `data/blocked.json` — вопрос по подозрительному мероприятию. Ответ внести в `src/exclusions.json` (`"<id>": {"решение": "исключить|оставить", "дата": "ДД.ММ.ГГГГ", "причина": "…"}`) и запустить workflow вручную (Actions → Run workflow). «Каналы продаж» при этом обновляются в любом случае.

## Что править
- Цели мероприятий — `GOAL` в `src/mk_pf3.py`; длинные названия — `SHORT` в `src/mk_dash.py`.
- Тексты и правила карточек — `src/mk_cards.py`, `src/mk_html.py`, `src/dash_template.html`, `src/help_dash.html`.
- Каналы (объединение дистрибьюторов) — `GROUP_RULES` в `src/build_channels.py`.
- После правки шаблона или оболочки пересобрать дашборды: `python3 -s src/mk_shell.py …` (см. docstring) и заменить файлы в портале (правило Z.2).

## Секрет
В `bs-reports` → Settings → Secrets and variables → Actions: `AM_REPORTS_TOKEN` — fine-grained токен с доступом `Contents: Read and write` только к `am-reports`. Срок действия — 1 год: продлить заранее, иначе публикация остановится.

## Ручной запуск расчёта (запасной вариант)
`cur/` и `prev/` — плоские папки CSV свежей и прошлой выгрузок (из `bs-reports/csv/` по коммитам). Затем:
`python3 -s src/build_all.py --src src --cur cur --prev prev --cur-time 'ГГГГ-ММ-ДД ЧЧ:ММ' --prev-time 'ГГГГ-ММ-ДД ЧЧ:ММ' --am .` (время МСК). Для «План-факт» генератора архив выгрузки — zip с папкой `csv_export/` внутри; таймаут обработки в браузере — 300 с.
Код выхода: 0 — всё собрано; 2 — «Портфель» остановлен проверкой; 1 — ошибка.
